# 机会猎手 OS · Opportunity Hunter

平面世界地图上的全球机会扫描：195 个经济体的发展阶段和宏观数据，加上 50 个主要经济体（约占 2026 年世界 GDP 92%）的产业画像——当前最热门的行业、已经成熟的产业、高速增长的行业，以及可关注的投资标的（指数 ETF、龙头股、债券、A 股 QDII）。画像截至 2026-10-08，不构成投资建议。

| 文件 | 内容 |
|---|---|
| `index.html` | 构建产物（单页，可直接发布为 Artifact） |
| `src/app.js` | 地图、机会评分、总览/国家/评分/方法四个面板 |
| `src/style.css` | 液态玻璃样式，浅色/深色两套 token |
| `src/body.html` | 页面骨架 |
| `src/data.js` | 生成文件：宏观、产业结构、出口结构与画像 |
| `src/geo.js` | 生成文件：简化后的国界 TopoJSON（按 ISO alpha-3） |
| `pipeline/fetch.sh` | 下载原始数据到 `.cache/`（约 6 MB，不入库） |
| `pipeline/build_geo.mjs` | 简化边界；中国、台湾、香港、澳门轮廓取自 DataV |
| `pipeline/build_data.mjs` | 合并 IMF、世界银行、WITS 数据与画像，并校验画像格式 |
| `pipeline/profiles.mjs` | 手写的 50 国产业画像、全球环境与来源清单 |

## 构建

```bash
npm install
npm run fetch   # IMF WEO、世界银行 WDI/WGI、WITS、Natural Earth、DataV
npm run geo     # src/geo.js
npm run data    # src/data.js
npm run build   # index.html
```

## 地图的四种着色

| 模式 | 指标 | 来源 |
|---|---|---|
| 机会评分 | 7 项指标的百分位加权平均（权重可在页面上调） | IMF WEO 2026 年 4 月、世界银行 WGI |
| 发展阶段 | 世界银行收入分组 | 世界银行 |
| 2026 增速 | 实际 GDP 增速，以世界平均 3.1% 为中性色 | IMF WEO 2026 年 4 月 |
| 热门赛道 | 某一赛道在各国画像中属于“最热 / 高增长 / 成熟” | 产业画像 |

## 机会评分

| 维度 | 指标 | 方向 | 均衡权重 |
|---|---|---|---|
| 增长动能 | 2026–2030 年实际 GDP 年均增速 | 越高越好 | 25% |
| 市场规模 | 2026 年名义 GDP（对数） | 越高越好 | 15% |
| 人口动能 | 2026–2031 年人口年均增速 | 越高越好 | 10% |
| 物价稳定 | 2026 年通胀与 2.5% 的距离 | 越低越好 | 15% |
| 财政空间 | 政府总债务 / GDP | 越低越好 | 10% |
| 外部平衡 | 经常账户 / GDP | 越高越好 | 10% |
| 法治 | 世界银行 WGI 法治指数 | 越高越好 | 15% |

每项先在全部经济体中换算成百分位，缺失项按剩余权重重新归一；至少要有增长项和 5 项指标才给分。另有“成长优先”“稳健优先”两组预设。

## 画像格式

`pipeline/profiles.mjs` 中每个经济体一项：`thesis`（一句话结论）、`hot` / `mature` / `growth`（每行 `[行业, 赛道, 依据]`）、`assets`（每行 `[类别, 名称, 代码, 理由]`）、`risks`、`watch`（近期看点）、`src`（来源键），可选 `gl`（IMF 4 月之后能找到的最新 2026 年增速预测）。`build_data.mjs` 会检查赛道、资产类别和来源键是否存在。

## 局限

- 评分只看宏观基本面，不含估值、流动性和治理事件；印尼评分靠前但年内股市大跌，就是两者背离的例子。
- IMF 4 月预测有的已经过时（例如台湾 5.2%，主计总处 5 月已上调到 9.64%），国家页同时列出最新预测。
- 中国台湾不在世界银行和 WITS 数据库中；孟加拉国未向 WITS 报送 2021–2023 年数据。
- 画像中的指数、价格、利率会很快过时；ETF 代码可能变更（如 GXG → COLO、ERJ → EMBJ），以交易所为准。
