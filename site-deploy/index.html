Claude Code 建站发布方案

Claude Code 改的是文件。只有「网站 = Git 仓库里的代码」的平台，它才能改完直接上线。Wix 和 Squarespace 的页面存在它们自己的数据库里，Claude Code 碰不到页面布局。

GitHub 仓库 + Cloudflare Pages推送代码 → 自动构建 → 1 分钟内上线

平台对比

核心问题：Claude Code 能不能改完直接发布
平台Claude Code 能改什么发布方式免费档可商用预览链接页面设计自由度结论
代码托管类 · 网站就是仓库里的文件
Cloudflare Pages全部：页面、样式、脚本push 到 GitHub 自动部署可以 带宽不限每个分支一个完全自由首选
Vercel全部push 自动部署不可 Hobby 限非商用，Pro $20/人/月每个分支一个完全自由，Next.js 最佳有预算时选
Netlify全部push 自动部署有额度限制每个分支一个完全自由，自带表单备选
GitHub Pages全部push 自动部署不适合 条款不面向商业网站无仅静态只做个人页
可视化建站类 · 页面存在平台数据库
WebflowCMS 内容、部分页面元素（官方 MCP / API）API 调用发布需付费站点套餐staging 域名设计器内自由，API 改布局受限要可视化编辑时选
WixVelo 代码、CMS 数据（Wix CLI / MCP）CLI 发布免费站带广告、无自定义域名有布局只能在编辑器里拖不推荐
Squarespace几乎不能，只有代码注入（Business 套餐以上）只能手动点发布无免费档无模板内自由不推荐

按各平台公开政策整理，套餐和条款可能已调整，以官网为准。

一次性配置

左边你做，右边我做
你 · 约 10 分钟
  1. 注册 Cloudflare 账号（免费）
  2. 进入 Workers & Pages → 创建 → Pages → 连接到 Git，授权并选择仓库 bitzac/project-uno
  3. 构建设置：框架选 None，构建命令留空，输出目录填 site，生产分支选 main
  4. （可选）在 自定义域 绑定你的域名，Cloudflare 自动配置 HTTPS
  5. （可选）在 Stripe 后台创建 Payment Link，把链接发给我
