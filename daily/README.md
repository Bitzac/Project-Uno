# UNO 日刊

个人杂志日刊，五个板块：户外运动、AI、科技前沿、政治经济、国际市场。每天美西 05:00 由定时任务检索公开报道、编辑、发布到同一个 Artifact 链接，每条附来源和日期。

- 在线阅读：https://claude.ai/artifact/SbEPYSRJ631p2CDYYBM4uB
- 出刊流程与编辑规则：[`EDITOR.md`](EDITOR.md)

| 文件 | 内容 |
|---|---|
| `issues/YYYY-MM-DD.json` | 每期内容，一天一个文件，是唯一的数据源 |
| `src/app.js` | 把一期 JSON 渲染成杂志页：封面结论、五个板块、行情表、日程、往期切换 |
| `src/style.css` | 液态玻璃 + 极细线条 + 粗体排版，明暗两套配色 |
| `src/body.html` | 顶栏骨架 |
| `build.mjs` | 校验所有期刊并把最新 30 期内联进页面 |
| `index.html` | 构建产物，直接发布为 Artifact |

## 构建

```bash
node build.mjs   # 校验 issues/*.json，生成 index.html
```

校验项包括：五个板块齐全且顺序固定、每条都有日期和 https 来源、行情涨跌幅是数字或标注了口径。任何一项不过都会报错并停止生成。

## 版面

| 区块 | 内容 |
|---|---|
| 刊头 | 期号、日期、条目数 |
| 封面 | 当天最重要的一条 + 五个板块各一句结论 + 行情速览 |
| 板块 | 头条（2–3 段 + 关键数字）+ 侧栏（积分榜或要闻）+ 简讯 |
| 国际市场 | 18 个品种的行情表，涨跌幅条形使用同一比例尺 |
| 日程 | 未来 30–60 天的赛事、议息、选举等 |

右上角可切换往期，以及「红涨绿跌 / 绿涨红跌」配色（只存在本机浏览器）。
