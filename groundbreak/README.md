# 破土 · Groundbreak

面向中国大陆的初创企业投融资平台：**公开晒产品，不公开卖股权**。借鉴 Product Hunt 的每日首发榜和 Kickstarter 的全有或全无众筹，把首发和众筹产生的需求数据算成“信号分”，只推送给认证过的合格投资者。

| 文件 | 内容 |
|---|---|
| `proposal.html` | 产品方案：结论、市场数据、对标、三层架构、合规设计、收入测算、风险、路线图、来源 |
| `src/data.js` | 14 个虚构示例项目、信号分权重、创业者后台示例数据 |
| `src/app.js` | 首发榜、众筹、投资人专区、创业者后台四个视图和项目详情面板 |
| `src/style.css` | 液态玻璃样式，与 health-os 同一套视觉语言 |
| `src/body.html` | 页面骨架 |
| `index.html` | 构建产物（可交互原型） |

## 构建

```bash
node build.mjs   # 生成 index.html
```

`index.html` 和 `proposal.html` 都不含 `<html>/<head>/<body>`，发布为 claude.ai Artifact 时由平台补齐。

## 三层架构

| 层 | 借鉴 | 谁能看 | 产出 |
|---|---|---|---|
| 首发榜 | Product Hunt | 所有人 | 曝光、加权票 |
| 众筹 | Kickstarter | 所有人 | 达成率、支持人数、交付记录 |
| 对接 | AngelList | 仅认证合格投资者 | 关注、约谈 |

## 信号分

`需求验证×30% + 执行交付×20% + 经营数据×20% + 社区热度×15% + 信息完整×15%`，每项 0–100。信号分 ≥ 60 的项目才进入投资人专区。

## 原型里的约束

- 访客看不到项目是否在融资，也看不到轮次、金额、出让比例（证券法第九条：非公开发行不得公开劝诱）。
- 众筹回报只能是产品或服务（防范和处置非法集资条例第二条）。
- 投票、关注、身份只存在本机 `localStorage`，所有支付和约谈都是演示，不发出任何请求。
