# 人口潮汐 · Population Tides

平面世界地图上的人口回测与模拟：中国 31 个省级单位、美国 50 州 + DC、欧洲 40 国，1800–2100 年逐年展示人口增减和迁移流向。过去用普查和历史重建，未来用 UN WPP 2024 低/中/高三种情景；省/州的未来分布用经过回测选出的模型外推。

| 文件 | 内容 |
|---|---|
| `index.html` | 构建产物（单页，可直接发布为 Artifact） |
| `src/app.js` | 地图、时间轴、流向弧线、总览/地区/回测/方法四个面板 |
| `src/style.css` | 液态玻璃样式，浅色/深色两套 token |
| `src/body.html` | 页面骨架 |
| `src/data.js` | 生成文件：人口、净迁移、流向、回测结果（单位：千人） |
| `src/geo.js` | 生成文件：简化后的边界 TopoJSON |
| `pipeline/fetch.sh` | 下载原始数据到 `.cache/`（约 110 MB，不入库） |
| `pipeline/build_geo.mjs` | 简化边界、计算质心 |
| `pipeline/build_data.py` | 人口重建、迁移残差、重力模型、回测 |

## 构建

```bash
npm install
npm run fetch   # 下载 UN WPP、OWID、维基普查表、边界
npm run geo     # src/geo.js + pipeline/centroids.raw.json
npm run data    # src/data.js（需要 pandas、lxml）
npm run build   # index.html
```

## 数据来源

| 时段 / 内容 | 来源 | 可信度 |
|---|---|---|
| 1950–2023 国家总量、欧洲各国、净迁移 | UN World Population Prospects 2024 | 高 |
| 2024–2100 | UN WPP 2024 低 / 中 / 高情景 | 情景 |
| 美国各州 1790–2020 | 美国普查（维基百科汇总表） | 高 |
| 中国各省 1953–2020 | 历次人口普查（维基百科汇总表），按现行政区调整 | 高 |
| 中国各省 1820 / 1851 / 1880 | 梁方仲辑嘉庆二十五年册籍；曹树基《中国人口史》第五卷推算 | 低（约 ±15%） |
| 中国各省 1912 / 1936 | 民国统计，修正安徽、广西、青海等明显漏报 | 低 |
| 欧洲各国 1800–1940 | OWID / Gapminder（现代国界）；英国、爱尔兰按普查改写 | 中 |
| 跨洲移民 | 美国 DHS 年鉴表 2（按来源地区）、各国移民构成、回流率；1944–50 德裔被驱逐 | 中 |

## 模型

| 环节 | 做法 |
|---|---|
| 省/州历史分布 | 普查份额；普查年之间按对数份额线性插值，再乘国家总量 |
| 省/州未来分布 | `ln s(T+h) = ln s(T) + r·Σφᵏ`，r 为过去 20 年份额年均变化；φ 由回测选定 |
| 净迁移（中、美） | 残差法：十年增量 − 全国自然增长率 × 期初人口 |
| 战乱与饥荒 | 太平天国、西北战争、丁戊奇荒、1942 河南、1959–61 期间受灾省份超出自然增长的减少记为超额死亡 |
| 净迁移（欧洲） | 1950 后 UN 各国净迁移；1950 前只建模跨洲移民与战后驱逐 |
| 流向 | 净迁出地 → 净迁入地，双约束重力模型（距离幂 −1.2 至 −1.8）；跨洲流量按纽约、旧金山口岸分配到各州 |

## 回测

假设国家总量已知，只检验“省/州份额分配”是否准确。校准样本（美国 1960–2010 起点，中国 1982、1990 起点）合并后选 φ，再用 2000、2010 起点做留出检验。

| 方法 | 美国 2000→2020 各州 MAPE | 中国 2000→2020 各省 MAPE |
|---|---|---|
| 份额不变（基准） | 8.2% | 11.8% |
| 趋势外推，φ = 0.95（采用） | 5.1% | 8.3% |

完整逐案例结果在页面“回测”面板。单独用中国样本会选出 φ = 0：1964–1982 年户籍管制、上山下乡、三线建设让当时的趋势不可外推，所以采用中美合并样本。

## 局限

- 残差法假设同一国内各地自然增长率相同，高生育率地区会被部分误读为迁入。
- 重力模型给出的是量级合理的分配，不是登记到的具体路线。
- 1950 年前欧洲内部迁移没有建模；俄罗斯整国计入欧洲。
- 台湾、香港、澳门不在数据中（地图上为灰色）；1860 年前美国普查不含原住民。
- UN 三种情景只在生育率上不同，迁移假设相同，因此未来流向不随情景变化。
