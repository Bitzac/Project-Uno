结论先行

三句话讲完这门课

本质

LLM 是一台条件概率机器

p(x1…xT) = ∏t p(xt | x<t)

整段文本有 |V|T 种可能，无法直接建模。链式法则把它拆成 T 道「从十几万到 25 万个 token 里选 1 个」的分类题。

结构

只有 Attention 让位置之间交流

softmax(QK⊤/c + M) · V

MLP 对每个位置独立计算；注意力用 query·key 打分、对 value 加权求和。因果掩码 M 只允许看过去，代价是随长度 T² 增长。

训练

训练就是降低交叉熵

L(θ) = −∑t log pθ(xt | x<t)

和图像分类是同一个损失，只是类别数等于词表大小。用 mini-batch SGD / Adam 更新所有权重；词表在训练前就定好，不参与更新。

0:10:00链式法则长度 T 的序列有 |V|T 种组合，不能逐一给概率。分解成条件概率后，每一步只是 |V| 选 1。p(x1:T) = ∏ p(xt | x<t)
0:13:42Embedding按 ID 读取矩阵的一行，得到 d 维向量；矩阵本身是训练出来的。序列前加固定的 BOS token；词表通常预留几千个特殊 token。E ∈ ℝ|V|×d
0:16:49Logits → 概率位置 t 输出一个 |V| 维向量，softmax 后变成下一个 token 的分布。它只能依赖 x0…xt−1。p(xt|·) = softmax(ut)
0:25:30生成与采样从 BOS 或 prompt 出发，采样一个 token 后追加回输入，循环。训练时整句已知；生成时只能一个个来。温度 τ、Top-k 见下方演示
0:35:07训练目标负对数似然：把每个位置上真实 token 的 −log 概率加起来，交给 SGD 或 Adam 当黑盒优化。−∑t log softmax(ut)xt
0:38:19Transformer 骨架Attention 与 MLP 交替堆叠。MLP 对每个位置单独计算、共享参数，可完全并行；位置之间唯一的信息通道是 Attention。整体端到端自动微分
0:41:26单头注意力每个输入投影成 query、key、value。q 与各 k 的内积经 softmax 成为权重，输出是 v 的加权和。W 都是训练出来的，机制只是模板。qt=htWQ, ki=hiWK, vi=hiWV
0:53:00为何不用巨型 MLP把所有 token 拼起来喂一个 MLP：参数随 T 增长（T 可达百万），换个长度就得换参数。注意力的参数量与 T 无关，在「预设结构」和「留给模型的自由度」之间取了平衡。卷积也能用，效果不如注意力
0:57:09矩阵形式 + 因果掩码写成矩阵后输出依赖全部位置，会偷看未来。在 QK⊤ 上三角加 −∞，softmax 后权重变 0，位置 t 只看 ≤ t。softmaxrow(QK⊤/c + M)V

1:11:13残差 + Norm每个子层外包残差连接和 RMSNorm。Pre-norm 与 Post-norm 的区别是 Norm 放在子层之前还是之后。原理见下半「残差」「RMSNorm」

1:16:27真正的非线性只对输入非线性（如 x²）不算：令 z = x² 就还原成线性模型。这里说的非线性是对参数 θ 非线性。θ12x1 才算
1:19:31监督学习四件套数据对、模型 hθ、损失、优化器。框架与线性模型完全相同，只换了模型。{(x(i), y(i))}i=1..n
1:22:50回归：MSE平方误差的平均。它等价于假设「标签 = 预测 + 高斯噪声」时的负对数似然。y = hθ(x) + ε, ε ~ 𝒩(0, σ²)
1:24:58多分类：交叉熵模型输出 k 个 logits，softmax 成概率，取真实类的 −log 概率。PyTorch 的 CrossEntropyLoss 直接接收 logits。LLM 的损失就是 k = |V| 的这个
1:34:53GD vs SGDGD 用全部样本的平均梯度。SGD 每步随机抽一个样本，它的梯度期望正好等于全量梯度，单步有噪声，平均方向一致。𝔼j[∇Jj(θ)] = ∇J(θ)
1:40:04为什么用 SGD① 全量梯度太贵；② 各样本梯度高度相关，全算是浪费；③ 单步偏差会被后续步数抵消。2015 年约百万样本，如今以万亿 token 计
1:42:12非凸与局部极小主流观点不认为 SGD 靠噪声「跳出局部极小」。高维中要求所有方向 Hessian 半正定很难满足，坏的局部极小可能很少。这是假说。可用 Kac–Rice 公式计数
1:47:24Mini-batch每步取 B 个样本，在噪声与成本间折中。只算一个样本会让上万张 GPU 大多闲置。θ ← θ − η·(1/B)∑∇Jj
1:51:34ReLU 神经元房价「先平后升」可用 max(wx+b, 0)+c 拟合。「激活」一词来自神经元超过阈值才放电的类比。ReLU(t) = max(t, 0)
1:56:49两层网络中间层像「步行便利度」「学区质量」这类原始数据里没有的隐特征，由输入非线性组合而来。写成矩阵后无需逐个展开。a = ReLU(W1x+b1)，参数 md+m

2:12:40堆叠与维度匹配层数约等于矩阵乘法次数。上一层输出维度必须等于下一层输入维度。输入维度很大时先压缩，之后长期保持不变。语言：约 25 万维 → 约 2K 隐维

总结

整门课就是这一条链

文本→BPE 子词→ID→Embedding→(Attention + MLP + 残差 + RMSNorm) × L→logits→softmax / τ→采样↺

训练时同一条链反着走：交叉熵损失经反向传播，用 mini-batch SGD / Adam 更新链上所有矩阵。下表把模型发布时常见的改动对应到链上的环节。

发布说明里的改动改的是哪一环实例（官方 config / 公告）
新 tokenizer、词表扩大分词Qwen3 → Qwen3.5：151,936 → 248,320；Claude Opus 4.7 换新 tokenizer
线性 / 混合注意力注意力的 T² 成本Qwen3.5-397B：每 4 层中 3 层线性注意力
GQA、更少的 KV 头多头注意力（推理显存）Qwen3.5-397B：32 个 query 头共用 2 个 KV 头
MoE 混合专家MLP 层DeepSeek-V3：总参数 671B，每 token 只激活 37B
更长上下文序列长度 TQwen3.5 原生 262,144 token
temperature / top-k / top-p生成采样API 参数，只改采样方式，不动权重
