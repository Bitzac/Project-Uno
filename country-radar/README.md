# 国家蛛网 · Country Radar

可交互的国家蛛网（雷达）模型。第三版覆盖 26 个国家、10 个维度、30 项公开指标，并带一个“理想生活”模块：用选择题或滑块设定你看重什么，按匹配度给所有国家排序。

雷达图一次最多叠 4 个国家（4 个对比槽位各有固定颜色和标记形状，取消一个不会给其他国家换色），其余国家看排名、热力表和小雷达图墙；这些长列表可以按地区筛选，排名始终是全部 26 国里的名次。

| 文件 | 内容 |
|---|---|
| `src/data.js` | 26 个国家（含入选理由）、10 个维度、30 项指标的原始值、年份、区间端点和来源；理想生活的预设和选择题 |
| `src/app.js` | 打分（缺失数据按其余指标平均）、雷达图与小雷达图（SVG）、对比槽位、总览、维度详解、理想生活、方法与来源四个视图 |
| `src/style.css` | 液态玻璃样式，与 health-os、groundbreak 同一套视觉语言 |
| `src/body.html` | 页面骨架 |
| `index.html` | 构建产物（可交互页面） |

## 构建

```bash
node build.mjs   # 生成 index.html
```

`index.html` 不含 `<html>/<head>/<body>`，发布为 claude.ai Artifact 时由平台补齐。

## 十个维度

| 维度 | 指标 | 主要来源 |
|---|---|---|
| 医疗 | 预期寿命、UHC 服务覆盖指数、个人自付占比、每千人医生、医保覆盖率 | 世界银行 WDI、WHO |
| 基建 | LPI 基础设施、固定宽带中位速率、移动网络中位速率 | 世界银行 LPI 2023、Ookla 2026-03 |
| 治安 | 故意杀人率、Gallup 法律与秩序指数 | UNODC、Gallup 2024 |
| 经济 | 人均 GDP（PPP）、人均实际 GDP 年均增速 2019→2025、失业率 | 世界银行 WDI、ILO |
| 机会 | 全球创新指数、社会流动性指数、青年失业率 | WIPO 2025、WEF 2020、ILO |
| 教育 | 预期受教育年限、平均受教育年限、本国最高排名大学 | UNDP HDR 2025、QS 2027 |
| 环境 | PM2.5 人口加权浓度、环境绩效指数 | WashU ACAG、耶鲁 EPI 2026 |
| 可负担 | 本地购买力指数、房价收入比 | Numbeo 2026 年中 |
| 治理与自由 | 政府效能、清廉指数、WJP 法治指数、自由之家评分 | WGI 2025 版、CPI 2025、WJP 2025、FH 2026 |
| 工作与幸福 | 生活评价、年均工作时长、法定带薪假 + 公共假日 | WHR 2026、PWT 11、各国劳动法（汇总自维基百科） |

## 打分

1. 每项指标按固定区间换算成 0–100：区间端点取全球大致的底部和前沿，不是这些国家之间的相对排名。收入、网速、杀人率、房价收入比、大学排名用对数刻度。
2. 维度分 = 维度内指标等权平均（缺失指标不计入，表中标 *）；综合分 = 所选维度等权平均。
3. 理想匹配度 = `100 × (1 − √(Σ w·缺口² ÷ Σ w·t²))`，w 为重要程度（0–3），t 为目标分，缺口 = max(0, t − 国家得分)。超过目标不加分；标为“必须”且差 10 分以上记为硬伤。

## 局限

- 国家均值掩盖城乡和地区差异。
- 部分指标年份不一致（杀人率中国最新为 2020 年），医保覆盖率各国口径不同。
- 清廉指数、自由之家、WJP、Gallup、幸福报告依赖问卷或专家打分；Numbeo、Ookla 为众包数据。
- 以本国居民为视角，没有计入签证、语言、华人社区等移居者因素。“可负担”按当地工资衡量，带海外收入生活的人应直接看物价（Numbeo 生活成本+房租指数，越南 19.0、泰国 25.8，见页面备注）。
- 爱尔兰、新加坡的人均 GDP 和增速被跨国公司账面利润推高。
- 德国法定假期按维基百科汇总表改为 20 + 10 = 30 天（第一版为 20 + 9）。
