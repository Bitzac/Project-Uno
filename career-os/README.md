# 事业 OS · Career System

个人事业系统：按能力分模块构建，每个模块对每个项目单独记录进度。第一版只有 **融资能力（中国大陆）**，其余模块（产品、增长、团队、法务、财务）在左栏显示为「规划中」。

融资模块针对仓库里两个可以规模化的项目预置了内容：**身体健康 OS**（`health-os/`）和 **破土 Groundbreak**（`groundbreak/`），也可以在页面里新增项目。

## 融资模块的 6 个视图

| 视图 | 回答什么 | 可视化 |
|---|---|---|
| 总览 | 你在哪一步、下一轮是什么、这周先做哪 3 件事 | 进度环、市场数字、对口资方排行、阶段时间线 |
| 轮次地图 | 种子到上市每轮拿多少、让多少、要有什么 | 对数刻度金额区间图、出让比例图、上市板块门槛表 |
| 找资方 | 11 类资方里先找谁、找哪几家 | 资方类型 × 项目适配度热力矩阵、机构卡片（附公开案例链接） |
| 路演 | BP 怎么写、机构内部怎么过会、会被问什么 | 过会流程图、12 页 BP 结构（按项目预填要点）、你的漏斗 |
| 交割流程 | 一轮融资从准备到打款的每一步 | 阶段甘特图、可勾选步骤清单（含国资、美元支线） |
| 我的进度 | 完成了多少、目标机构谈到哪 | 各阶段完成度、目标机构看板 |

## 文件

| 文件 | 内容 |
|---|---|
| `src/fund-data.js` | 融资模块内容：阶段与步骤、轮次、上市板块、资方类型、赛道适配度、机构、市场数据、来源表 `SRC` |
| `src/projects.js` | 两个内置项目的 BP 要点、风险、必问问题和适配度说明 |
| `src/core.js` | 模块注册表、项目切换、数据层（云端 db，不可用时退回浏览器存储）、抽屉、提示 |
| `src/fund.js` | 融资模块 6 个视图的渲染与交互 |
| `src/boot.js` | 启动 |
| `src/style.css` | 液态玻璃 + 极细线条 + 粗体排版，明暗两套配色，与 health-os、groundbreak 同一套视觉语言 |
| `src/body.html` | 页面骨架 |
| `build.mjs` | 校验内容并内联成 `index.html` |
| `index.html` | 构建产物，直接发布为 Artifact |

## 构建

```bash
node build.mjs   # 校验并生成 index.html
```

校验项：每条来源都有 https 链接和日期；正文里 `[[key]]` 形式的引用和每个 `src` 都能在 `SRC` 里找到；步骤 id 唯一且属于已知阶段；每家机构都有公开案例和链接；每个赛道对每类资方都有适配度和理由。任何一项不过都会报错并停止生成。

`index.html` 不含 `<html>/<head>/<body>`，发布为 claude.ai Artifact 时由平台补齐。发布时声明 `db` 和 `user` 能力。

## 数据结构（云端）

```
projects/{pid}                     新增的项目：name, sector, stage, note, order
projects/{pid}/steps/{stepId}      步骤进度：done, note, at
projects/{pid}/targets/{instId}    目标机构：status(target|contact|meet1|meet2|ts|dd|closed|pass), note, at
```

内置项目（`health-os`、`groundbreak`）的定义在 `src/projects.js` 里，不写入数据库；数据库只存你的进度、备注、目标机构和新增项目。云端不可用时，同样的数据存在浏览器 `localStorage`（键前缀 `cos.`），只在这台设备上可见。

## 口径

- 数字和法规条文都附来源和日期，截至 2026 年 10 月。
- 资方适配度（0–5）是本系统对种子 / 天使轮的判断，理由写在每一格旁边。
- 机构只列公开可查的投资案例，不代表它现在一定在投，也不含任何联系人信息。
- 内容不构成投资或法律意见。
