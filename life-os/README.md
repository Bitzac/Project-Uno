# 人生路径 OS · Life Path OS

把 0–28 岁的五段经历（呼和浩特 → 美国 → 北京 → 杭州 → 环游中国）画成时间轴和地图，再用 6 座南方沿海城市 × 7 项指标的打分模型回答“下一步在哪生活、怎么生活”。

当前结论（第 2 版）：**上海做基地 8 个月，1–2 月去深圳过冬并对接香港，7–8 月回呼和浩特避暑**，基地锁定 3 年。第 1 版推荐北京；用户随后排除了北京常住，要求南方沿海、接近全球资源、投资人多、对创业者友好，并确认储备够 18 个月、母亲愿意离开呼和浩特、事业方向未定。

| 文件 | 内容 |
|---|---|
| `src/data.js` | 人生阶段、决策记录、候选城市指标（每项标“实/估”）、香港、权重方案、月均温、来源 |
| `src/app.js` | 时间轴、停留年数、地图（可点亮去过的省份）、选城模型、气温图、预算与储备计算、事业关口 |
| `src/style.css` | 液态玻璃样式，浅色/深色两套 token；人生阶段固定使用分类色 1–5，深圳冬站用色 8，上海基地用墨色 |
| `src/body.html` | 页面骨架：结论 → 决策记录 → 路径 → 选城 → 生活 → 风险 → 总结 → 来源 |
| `index.html` | 构建产物 |

## 构建

```bash
node build.mjs   # 生成 index.html
```

省界和美国州界直接读取 `../popflow/src/geo.js`，不重复存一份。`index.html` 不含 `<html>/<head>/<body>`，发布为 claude.ai Artifact 时由平台补齐。d3 7.9.0 和 topojson 3.0.2 从 cdnjs 加载。

## 选城模型

候选：上海、深圳、杭州、广州、厦门、珠海。香港单独评估：母亲在用户取得永久居民身份前不能以受养人身份长住，所以只作为门户。

| 指标 | 原始数据 | 0–100 分 |
|---|---|---|
| 创业生态 | Startup Genome 2025 全球排名 | 100 × (51 − 排名) ÷ 50；未进前 40 按第 46 名 |
| 投资人 | 2025 年一级市场投资事件数（IT桔子） | 100 × √(事件数 ÷ 1,174) |
| 全球连接 | 门到门到上海或香港的小时数 | 100 × e^(−0.35 × (小时 − 0.5)) |
| 母亲医疗 | 门到门到最近的复旦版 A++++ 级医院（小时） | 100 × e^(−0.25 × (小时 − 0.5)) |
| 生活成本 | 两人月支出 = 租金 × 75㎡ + 生活费 + ¥1,000 医疗预留 | 100 × 最低月支出 ÷ 本市月支出 |
| 气候 | 1 月 / 7 月均温 | 100 − 夏季超 24°C × 10 − 冬季低于 12°C × 5 |
| 空气 | PM2.5 年均浓度 | 100 × (1 − (PM2.5 − 10) ÷ 30) |

## 数据可信度

标“实”的数字有一手或权威媒体来源，页面底部列出链接。标“估”的包括：各城市租金与生活费、广州/厦门/珠海的投资事件数（来源只给出单城 < 362 起的上限）、厦门/珠海的 PM2.5、门到门时间、月均温。
